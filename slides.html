O coração do desafio

O scoring model determinístico

A prioridade deve ser calculada por regras explícitas — não por LLM. Rodado duas vezes no mesmo repositório: mesmo resultado.

Critérios a considerar:

  • Severidade base do achado (Crítica=100, Alta=70...)
  • Achado de segurança + questionário em 30 dias → multiplicador
  • Alto esforço + release em 14 dias → penalidade
  • Risco de perder cliente enterprise → amplifica acesso a dados
def score(finding, ctx):
    base = SEVERITY_MAP[finding.severity]

    # segurança + auditoria próxima
    if ctx.days_until_audit <= 30:
        if finding.category == "security":
            base *= 2.0

    # alto esforço + release próxima
    if ctx.days_until_release <= 14:
        if finding.effort > 8:
            base *= 0.5

    return Priority.from_score(base)

⛔ Scoring não-determinístico (resultado diferente entre execuções) = desclassificado como entrega técnica.

IA no pipeline

Gemini para enriquecer — não para decidir

O Gemini (API grátis) enriquece o campo Impacto em linguagem de negócio. A detecção e a prioridade vêm das ferramentas e do scoring model.

Setup: crie conta em aistudio.google.com → Get API key → export GOOGLE_API_KEY=...

import google.generativeai as genai

genai.configure(api_key=os.environ["GOOGLE_API_KEY"])
model = genai.GenerativeModel("gemini-1.5-flash")

def enrich_impact(finding, ctx):
    prompt = f"""
    Empresa: {ctx.name}, {ctx.mrr} MRR.
    Achado: {finding.description}
    Escreva em 1-2 frases o impacto de negócio.
    """
    return model.generate_content(prompt).text

⚠️ A IA erra — ela inventa problemas e deixa passar outros. Validar o output da IA vale pontos no critério de avaliação.
